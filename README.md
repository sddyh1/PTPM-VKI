# Лабораторная работа №3. Регистрация

Проект продолжает вариант из ЛР1 и учитывает исправления проверки логина и пароля из ЛР2. Контроллер получает логин, пароль и подтверждение. При первом вводе он вызывает валидатор и сохраняет результат в SQLite. При повторном вводе той же тройки он читает сохранённый результат. В обоих случаях контроллер передаёт имитатору сервера и возвращает одну и ту же строку — сообщение об успехе или причину отказа.

## Структура проекта

- `src/` — валидатор, контроллер, SQLite и классы ввода и отправки результата.
- `tests/` — тесты приложения.
- `main.py` — запуск программы.

## Запуск

Из корня проекта, Python 3.10 или новее. Для программы и тестов достаточно стандартной библиотеки.

```powershell
python main.py
```

Пример для проверки — логин `student_3`, пароль и подтверждение `Учебный7!`. Все три значения вводятся через `input()` и видны в консоли. Используйте вымышленные данные: по условию работы введённые значения сохраняются в локальном файле `registration.sqlite3`. Имитатор сервера выводит только результат в консоль.

## Тесты

```powershell
python -m unittest -v
```

Интеграционные тесты проверяют совместную работу контроллера, валидатора и SQLite. Среди сценариев — повторный запрос, изменение одного поля, удаление записи и повтор после сбоя отправки. Заглушки из `unittest.mock` подменяют ввод и отправку. Отдельный тест запускает точку входа программы и проверяет результат после повторного открытия файла БД.

Для измерения покрытия можно установить `coverage` и выполнить:

```powershell
python -m coverage run --branch --source=. -m unittest
python -m coverage report --omit="tests/*" -m
```
